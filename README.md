Honeybear Guest Lodge Website
A luxurious eco-lodge website inspired by the Aguas de Ibiza aesthetic, featuring three distinct voice tones: Poetic, Luxurious, and Corporate.

🖼️ Adding Your Images
Please add your provided images to the public/images/ directory with the following names:

Required Images:
hero.jpg - Main hero image (sunset garden shot recommended)
standard-room.jpg - Standard room image
wellness-suite.jpg - Wellness suite image
family-suite.jpg - Family suite image
wellness.jpg - Wellness/relaxation area image
gallery-1.jpg through gallery-8.jpg - Gallery images (use your best 8 images)
Recommended Image Mapping:
From your provided images, here's what I recommend:

hero.jpg - Use the sunset garden exterior photo
standard-room.jpg - Use one of the simpler room photos (twin beds or standard setup)
wellness-suite.jpg - Use the room with woven baskets and peacock art
family-suite.jpg - Use the spacious room with living area
wellness.jpg - Use the dining area or garden view
gallery-1 to gallery-8 - Use all your best room, dining, and detail shots
🎨 Features
Three Voice Tones: Switch between Poetic, Luxurious, and Corporate content
Smooth Animations: Fade-in effects on scroll
Responsive Design: Optimized for all devices
Elegant Typography: Playfair Display + Inter fonts
Earth Tone Palette: Inspired by your lodge's warm, natural aesthetic
Full Sections: Hero, Philosophy, Rooms, Wellness, Experiences, Location, Gallery, CTA, Footer
🚀 Getting Started
bun install

bun run dev
Open http://localhost:3000 to view the site.

📝 Customization
Edit content in src/app/page.tsx
Modify colors in src/app/globals.css
Add more images to the gallery section
🎯 Tone Switcher
Use the floating tone switcher in the top right to toggle between:

Poetic: Soft, atmospheric, nature-inspired language
Luxurious: Elegant, refined, boutique-hotel tone
Corporate: Professional, clear, business-friendly
Built with Next.js, TypeScript, Tailwind CSS, and shadcn/ui
